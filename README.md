# RecipeLingo — Recipe Translator

A Chrome extension built with WXT, React, and TypeScript.

Translate Cookidoo recipes into your preferred language while preserving guided cooking information. Open a Created Recipe and choose its source language in the extension popup. Keep the popup open until translation finishes; closing it may stop the in-flight work.
